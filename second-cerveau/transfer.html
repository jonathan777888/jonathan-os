Sauvegarder et transférer mon Second Cerveau

Cette page fonctionne uniquement sur ton navigateur : aucune donnée n’est envoyée à un serveur. Si tu veux récupérer tes anciennes notes du site GitHub Pages vers le nouveau site Vercel, utilise les deux étapes ci-dessous sur le même appareil et avec le même navigateur que précédemment.

1. Télécharger mon ancienne sauvegarde

Ouvre cette page depuis l’ancien site GitHub Pages, puis télécharge ton fichier. Seules les données du Second Cerveau présentes dans ce navigateur seront exportées, sans jetons de connexion ni clés secrètes.

Domaine actuel : • Entrées trouvées : …

2. Restaurer sur le nouveau site

Va sur la page de transfert Vercel, puis sélectionne le fichier téléchargé. Les données présentes dans ce navigateur seront préservées jusqu’à ta confirmation.

3. Reprendre mon travail

Une fois le transfert terminé, ouvrir mon espace local. Tu y retrouveras tes données de cet appareil. La synchronisation entre appareils exige toujours une connexion Supabase réparée.

Conseil : conserve le fichier dans un endroit privé, car il peut contenir tes notes personnelles.
